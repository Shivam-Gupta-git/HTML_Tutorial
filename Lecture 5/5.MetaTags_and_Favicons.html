Introduction of HTML

HTML stands for HyperText Markup Language. It is used to structure content on webpages

HTML provides different elements to organize headings, paragraphs, images, links, tables, and forms.

What are Semantic Tags?

Semantic tags are HTML elements that describe the meaning and purpose of their content. They make HTML code easier to understand and help assistive technologies interpret webpage structure.

1. The Header Tag

Published on October 22, 2026

The <header> tag represents introductory content for a webpage or a section. It commonly contains a logo, heading, or introductory information.

2. The Nav Tag

The <nav> tag defines a section containing important navigation links, such as Home, About,Services, and Contact.

3. The Main Tag

The <main> tag contains the primary content of a webpage. A page should generally have only one visible main element.

4. The Section Tag

The <section> tag groups related content under a common theme, usually with a heading.

5. The Article Tag

The <article> tag represents independent, self-contained content, such as a blog post, news story, or forum post.

6. The Aside Tag

The <aside> tag contains supplementary content related to the main content, such as related articles, tips, or a sidebar.

More Useful Semantic Tags

7. The Figure and Figcaption Tags

The <figure> tag groups self-contained content, such as an image, diagram, or illustration.The <figcaption> tag provides a caption for it.

8. The Details and Summary Tags

The <details> tag creates expandable content. The <summary> tag provides a visible heading that users can click to expand or collapse the content.

What is CSS ?

CSS stands for Cascading Style Sheets. It controls the appearance and layout of webpages.

9. The Time Tag

The <time> tag represents a date or time in a machine-readable format.

Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to style HTML elements by changing colors, fonts, spacing, borders, and layouts.

Quick Learning Tips

  • Practice HTML every day.
  • Use semantic tags where appropriate.
  • Learn CSS to improve webpage design.
  • Practice JavaScript to build interactive websites.
